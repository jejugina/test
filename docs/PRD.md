# BLOOM YOUR WAY 캠페인 PRD
작성일: 2026-11-05. 상태: 승인된 개선 범위 구현 완료. 참고 원문 대조·미확정 기획은 대기.

## 근거
사용자가 대화에 제공한 요구사항과 db 실제 코드가 기준이다.
링크된 PRD/To-do 원문은 열람하지 못했으므로 원문 확정본이 아니다.
회원관리는 PRD-USER.md를 별도 기준으로 유지한다.

## 프로젝트 개요·제품 목표
제주 동백마을 × A2O LITE 학교 교육용 가상 협업 캠페인.
20~30대 모바일 방문자가 마을의 매력을 이해하고 굿즈·체험에 관심을 갖게 한다.
핵심 슬로건 요구안: BLOOM YOUR WAY — 너의 방식대로 피어나.
실제 화면 문구·슬로건 변경은 승인 후 반영한다.

## 사용자 흐름
요구 흐름: 메인 영상 → 캠페인 스토리 → 굿즈 → 체험 → 방문 안내 → 알림받기.
현재 db는 스토리 → 체험 소개 → 굿즈 순서이며, 방문 안내가 없다.
섹션 재배치는 콘텐츠 순서 승인 후 진행한다.

## 디자인 가이드와 현재 차이
- 제안 가이드: 네온 핑크 #FF1494, 딥 바이올렛(정확한 색 미정), 홀로그램 그라데이션.
- 현재: 크림 #F5F1E6, 딥그린 #203E2D, 오렌지 #C4510B 버튼.
- 현재 레이아웃·사진·영상·굿즈 상세·꽃잎 효과를 보존한다.
- 권고: 기본 배경·브랜드 그린을 유지하고 승인된 요소에만 새 포인트 적용.
- 전면 리디자인·에셋 교체·폰트 패키지 추가는 하지 않는다.

## 비기능 요구사항
- 기존 기술 스택 유지, 불필요한 의존성 추가 금지.
- 320/375/390/430/768/1440px 가로 넘침 없음.
- 이미지 비율 유지, 영상 컨트롤·모바일 playsInline 유지.
- dialog 포커스·Escape·명확한 닫기, 라벨·대체텍스트·대비·터치 영역 검증.
- reduced-motion 대응 유지, 광고·분석 SDK/수집은 승인 전 추가 금지.
- secret key 사용 금지, .env.local 추적 금지.
- 빌드·린트와 실제 브라우저 검사, 미검증 플랫폼 명시.
- OG 이미지는 배포 환경에서 수집 URL·캐시까지 별도 확인.

## 완료 기준
승인된 요구만 구현하고 TODO의 완료 조건·6개 화면 크기 검증 기록이 충족되어야 한다.
미확정 정보와 테스트 불가 항목을 남겨두고 완료로 표시하지 않는다.
원문 문서 비교가 끝나기 전에는 PRD 전체 확정으로 간주하지 않는다.

## 사용자 결정 필요
1. 유지 승인 완료: 현재 굿즈 5종·캐릭터·이미지·영상.
2. 확정 체험 구성과 설명·시간·가격·대상 정보.
3. 방문 주소·운영 시간·일정·지도 목적지.
4. 포인트 적용 승인·반영: 네온 핑크 #FF1494, 딥 바이올렛 #542078, 홀로그램 라인. 기존 그린·오렌지·레이아웃과 슬로건 유지.
5. 번역 범위 승인·반영: 한국어·영어·중국어 간체, 캠페인 및 회원 화면. 카드뉴스·피라미드 UI도 번역하되 원본 이미지·영상 속 글자는 보존.
6. 알림은 저장 없는 시연으로 유지할지 여부.
7. 분석 이벤트는 설계 문서까지만인지 실제 수집을 원하는지.
8. 원문 PRD와 To-do 파일 첨부.


## 2026-11-05 승인 반영

- 모바일 details 메뉴, 교육용·비공식 협업 고지, 알림 미수집 안내.

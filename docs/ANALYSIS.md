## 구조와 기술
- Next.js 16.4.5 App Router, React/React DOM 19.3.0, TypeScript, Tailwind CSS 4, 일반 CSS.
- @supabase/ssr 0.12.7, @supabase/supabase-js 2.119.0. 새 라이브러리 불필요.
- app/layout.tsx: 메타데이터, 전역 스타일, Suspense 내부 회원 헤더.
- app/page.tsx: 캠페인 헤더, 메인 영상, 스토리, 체험 소개, 굿즈, 로고 애니메이션, 알림 팝업.
- app/goods-{data,showcase,detail,image}.tsx/ts: 5종 데이터, 컬렉션 이미지, 이름 버튼, native dialog 상세보기.
- app/falling-botanicals.tsx: SVG 꽃잎·잎사귀, CSS 애니메이션.
- /cards: SNS 카드 이미지·다운로드. /components/pyramid: 피라미드 화면.
- /signup, /login, /mypage 및 app/auth/: 회원관리.
- utils/supabase/: 서버·브라우저 클라이언트, 세션 갱신. proxy.ts가 Next.js 16 middleware 진입점.
- public/campaign/: 키비주얼, MP4, 카드뉴스와 이전 시안. public/goods/: 5종 각도별 시트와 세트 레퍼런스.
- scripts/: 시안 생성·카드 내보내기. 실행 시 에셋을 덮어쓰는지 확인 후 사용.

## 기획 차이와 보호
기존 그린·오렌지 디자인과 새 네온 핑크/딥 바이올렛/홀로그램 가이드는 다르다.
전체 교체는 하지 않으며 적용 범위·바이올렛 색상·그라데이션은 승인 후 결정한다.
현재 굿즈 5종과 이름, 캐릭터 이미지·명칭, 슬로건, 원본 이미지·영상은 유지한다.
외부 배포 사이트의 상품·프로그램·운영 일정은 복사하지 않는다.
회원 가입용 이메일 처리와 캠페인 알림 이메일 저장은 별개다.
알림 저장, 결제, 예약은 이번 단계에 구현하지 않는다.
